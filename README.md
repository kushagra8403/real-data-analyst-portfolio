# Real-World UK Data Analyst Portfolio

Six portfolio projects built around **genuine public datasets**, not synthetic data.

| # | Project | Source | Primary skills |
|---|---|---|---|
| 01 | Road Safety STATS19 | Department for Transport | Python, SQL, data quality, risk analysis |
| 02 | UK House Prices | HM Land Registry | Python, SQL, time series, regional analysis |
| 03 | Business Demography | ONS | Python, SQL, cohort/survival analysis |
| 04 | NHS A&E Performance | NHS England | Python, SQL, KPI analysis |
| 05 | Electricity & Renewables | DESNZ | Python, SQL, time series |
| 06 | Retail Sales | ONS | Python, SQL, retail KPI analysis |

## Why this repository is different

The first portfolio repository uses reproducible synthetic datasets. This repository deliberately uses **official real-world UK data**.

Each project contains:
- source and methodology documentation
- reproducible download script
- Python analysis
- SQL analysis
- dashboard specification
- dashboard preview with real published figures
- data notes

## Important

Raw datasets are not duplicated into Git when official files are large. The projects download them directly from the official publisher, keeping the repository lightweight and traceable.
